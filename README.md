# Projeto Integrador: Acessibilidade para a Qualidade de Vida

Site com as atividades de Robótica, Física e Tecnociência e Programação (2º ano C).

## Estrutura
- `index.html`: conteúdo da página
- `style.css`: visual (modo claro e escuro)
- `script.js`: abas, zoom, leitura em voz, cofre digital, refinador de prompts e calculadora nutricional
- `videos/`: vídeos das simulações de Robótica

## Como publicar no GitHub Pages
1. Crie um repositório e envie todos os arquivos, mantendo a pasta `videos`.
2. Vá em Settings > Pages.
3. Em Source, escolha a branch `main` e a pasta `/ (root)` e salve.
4. Aguarde alguns minutos e abra o link gerado.
